## Report an erratum

Typos, wrong technical statements, code that does not run — please open an issue. The "Report erratum" button at the bottom of every page pre-fills the chapter URL.

<a class="sl-link-button primary not-content" href={ISSUES}>Report an erratum</a>
<a class="sl-link-button secondary not-content" href={`${REPO_URL}/issues`}>Browse open issues</a>

> If your question is about a specific piece of code, including your environment (OS, Node version, `dsh --version`) speeds things up a lot.
